========================================
 СБОРКА И УСТАНОВКА
========================================

ТРЕБОВАНИЯ
----------
- Windows 10/11
- Python 3.11+
- pip install pyinstaller

БЫСТРАЯ СБОРКА (всё сразу)
---------------------------
Запустить от администратора:
    build_all.bat

Результат:
    dist\agent\windows32.exe     — агент для удалённого ПК
    dist\controller\test.exe     — твой контроллер

УСТАНОВКА АГЕНТА НА УДАЛЁННОМ ПК
----------------------------------
1. Скопировать на удалённый ПК:
      windows32.exe
      cert.pem
      key.pem

2. Запустить установку (один раз, от администратора):
      windows32.exe --install

   Или использовать тихую установку:
      install_silent.bat

3. Служба запустится автоматически.
   В диспетчере задач: процесс "windows32.exe"
   В службах Windows: "Windows 32 Runtime Service"

ИСПОЛЬЗОВАНИЕ КОНТРОЛЛЕРА
--------------------------
1. Запустить test.exe
2. Нажать "+ Добавить" → ввести имя, IP, порт (8765), пароль
3. Выбрать устройство → нажать "Подключиться"
4. Наблюдать за экраном
5. Нажать "⚡ Перехватить" — получить управление
   (пользователь на удалённом ПК теряет ввод)
6. Нажать "✋ Отдать управление" или Esc — вернуть ввод

ГОРЯЧИЕ КЛАВИШИ
---------------
F11   — полный экран / выход из полного экрана
Esc   — отдать управление (не закрывает окно)

СМЕНА ПАРОЛЯ
------------
В файле agent\server.py найди строку:
    PASSWORD_HASH = hashlib.sha256(b"changeme").hexdigest()

Замени "changeme" на свой пароль, пересобери агента.

УДАЛЕНИЕ АГЕНТА
---------------
    windows32.exe --remove
